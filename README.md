# python-beginner-projects
These are four python projects made while learning the language with the help of turotials and college experience. I wrote and tested each one myself.

# 1_task_manager.py
This project is a to do list that runs in the console. It lets you add new tasks, mark them as done and delete them when you don't need them anymore, and it shows a numbered list so you can see what is finished and what isn't. It also saves everything to a file, so your tasks are still there when you open it again.

# 2_expense_tracker.py
This project is a spending tracker. It lets you type in what you spent and what category it was for, such as food or travel, and it saves each one to a CSV file (like microsoft excel). When you ask for a summary it adds everything up and shows your total and how much you spent in each category. It also checks that you typed a real number and didn't leave anything empty.

# 3_weather_checker.py
This project is a weather lookup. You type in the name of a city and it finds it, then shows you the current temperature, the wind speed and a short description like rain or overcast. It gets this information live from a free weather website, and if there's no internet or the city doesn't exist it shows a message instead of crashing.

# 4_number_guessing_game.py
This project is a guessing game. The computer picks a secret number between 1 and 100, and you keep guessing until you get it. It includes hints telling you if you need to guess higher or lower. It counts how many guesses you took, remembers your best score and asks if you want to play again. It also stops you from typing letters instead of numbers.
